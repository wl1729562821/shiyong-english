# 实用英语

从零基础到日常沟通、再到旅行出行的英语 App（Flutter，Android / iOS / Windows）。
目标不是语法，而是：**听懂别人说的话，并用简单的英语回答。**

三门课按顺序学：基础入门（10 课）→ 日常沟通（20 课）→ 旅行出行（25 课），一共 55 课、
826 个单词词组、413 组“对方说 → 你回答”、55 段情景对话，全部可以朗读。
每个单词、每组问答、每句对话下面都可以写**自己的标注**。

## 每课怎么学（约 45 分钟）

1. **单词**（10 分钟）：先点 ▶ 听，猜意思，再看中文；每个词跟读 2 遍。可以“遮住中文”自测。
2. **听说**（15 分钟）：打开“盲听模式”，只听对方说的话，自己大声说出回答，再点开看答案。
3. **对话**（10 分钟）：先“听完整对话”，再“角色扮演”——轮到你时只显示中文，你说完再听示范。
4. **测验**（5 分钟）：10 题（复习课 15 题），正确率 ≥ 80% 自动完成这一课；答错的自动进生词本。
5. **复习**（5 分钟）：学新课前，把生词本和自己的标注过一遍。

**语速**：课程页、测验页右上角的语速按钮（显示当前倍速，如 0.9x）随时调，0.5x–2.0x，有 慢 0.7x / 正常 1.0x / 快 1.3x / 很快 1.6x 四个快捷档；调了之后下一句就按新语速读。建议刚开始 0.7x–0.9x 听清每个词，熟练后调到 1.0x 以上适应真实语速。

## 自己加标注

- 单词、问答卡片、测验讲解旁边的 ✎ 图标：点一下写标注；对话气泡旁边也有 ✎，或者**长按气泡**
- 标注显示在原文下面（黄色底），点它可以修改；清空内容保存 = 删除
- 「生词本 → 我的标注」：集中看所有标注，「全部复制」成文本贴到笔记里
- 「速查」也会搜标注里的字
- 同一句英文出现在好几课里（比如 Thank you.），共用同一条标注

## App 功能

- **课程**：三门课切换、总进度、学习天数、下一课入口
- **速查**：输入中文、英文或自己的标注（如“天气”“毛巾”“delay”），找到能直接说的句子，点一下就读；可以只看某一门课
- **生词本**：手动收藏 + 测验答错的，按错误次数排序，可全部播放和复习测验；切到「我的标注」看所有标注
- **设置**：语速（0.5x–2.0x）、发音人（美式 / 英式等）、字号（标准 / 大 / 特大）、学习开始日期、重置进度（生词本和标注保留）

## 安装

- **Windows**：已安装到 `D:\实用英语\`，桌面和开始菜单都有「实用英语」快捷方式。
  换电脑用：把 `release\实用英语-Windows.zip` 拷过去解压，运行里面的 `travel_english.exe`
- **Android**：`release\实用英语-Android.apk`，传到手机安装
- **iPhone**：要在 Mac 上编译签名，Windows 上做不了。没有 Mac 也可以：用 GitHub 云端 Mac 编译（`.github/workflows/ios.yml`），再在 Windows 上用 Sideloadly 装到手机。步骤见 [docs/iOS安装说明.md](docs/iOS安装说明.md)

学习记录和标注保存在本机：Windows 在 `%APPDATA%\com.travel\实用英语\`，重新安装不会丢。
旧版「旅行英语25天」的进度，第一次打开新版时会自动搬过来（旧文件不动）。

**朗读依赖系统的文字转语音引擎。** 如果设置页显示“无法朗读”：
- Android：手机「设置」里搜索“文字转语音”，首选引擎选支持英语的（Google 语音服务、讯飞等），并下载英语语音包
- Windows：「设置 → 时间和语言 → 语音」添加英语语音（中文 Windows 默认发音人是中文的，App 会自动改用英文发音人）

### Windows 快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+F | 跳到速查并开始输入 |
| 空格 | 课程页：全部播放 / 停止；角色扮演时 =“我说完了，听示范”；测验时 = 再听一遍 |
| R | 对话标签：开始角色扮演 |
| 1–4 | 测验：选第几个选项 |
| S | 测验：慢速再听 |
| Enter | 测验标签：开始测验；测验中：下一题 |
| - / = | 调慢 / 调快语速（每次 0.1x，小键盘的 - / + 也行） |
| Esc | 停止朗读；没在读时返回上一页 |

写标注时按空格、R 不会触发这些快捷键。

## 修改课程内容

`assets/courses/courses.json` 列出几门课和阶段；每门课一个目录，每课一个文件：
`assets/courses/basics/day01.json`、`assets/courses/daily/day01.json`、`assets/courses/travel/day01.json` ……
改完重新编译即可。

```json
{
  "words": [{"en": "boarding pass", "zh": "登机牌"}],
  "exchanges": [{"hear": "对方说的英文", "hearZh": "中文", "reply": "你的回答", "replyZh": "中文"}],
  "dialogue": {"title": "...", "other": "对方身份", "lines": [{"s": "o 或 me", "en": "...", "zh": "..."}]}
}
```

- 回答很通用（Thank you. 这类、放到别的问题下也说得通）时加 `"generic": true`，测验就不会用它出“听问题选回答”的题
- 句子里的数字写成英文单词（`twelve-oh-six` 而不是 `1206`），否则朗读会读成“一千二百零六”
- 加新课程目录时，记得在 `pubspec.yaml` 的 assets 里也加上（asset 目录不会递归）
- 改完跑 `flutter test`，会检查格式、重复、翻译缺失等问题

## 代码结构

```
lib/
  models/lesson.dart             课程、课、单词、问答、对话的数据模型
  data/lesson_repository.dart    读取 courses.json 和每课的 JSON
  services/tts_service.dart      朗读（await say() 读完返回 true，被打断返回 false）
  services/progress_service.dart 进度、生词本、标注、设置（shared_preferences）
  services/legacy_import.dart    Windows：从旧版目录导入数据
  quiz/quiz_builder.dart         出题（干扰项优先取同一课的内容）
  widgets/common.dart            朗读按钮、收藏按钮、标注显示和编辑框
  pages/home/                    课程 / 速查 / 生词本（含我的标注）/ 设置
  pages/lesson/                  单词 / 听说 / 对话 / 测验
  pages/quiz/                    测验页
android/.../TtsHandler.kt        Android TextToSpeech 通道
ios/Runner/AppDelegate.swift     iOS AVSpeechSynthesizer 通道
windows/runner/tts_channel.cpp   Windows SAPI 通道（三个平台协议相同）
```

测试：`flutter test`（内容校验、出题、进度与旧数据迁移、标注、手机/桌面界面流程、快捷键、大字号不溢出，共 44 个）；
`flutter test integration_test/tts_native_test.dart -d windows`（调用真实语音引擎）；
`flutter test integration_test/desktop_screens_test.dart -d windows --dart-define=SHOT_DIR=<目录>`（真实窗口里走一遍并截图）。
